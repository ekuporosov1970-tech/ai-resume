# Карьерный радар — модуль «Работа России»

Официальный API открытых данных портала «Работа России»; Python, без платного OpenAI API.

## Что делает
- Ищет вакансии по 14 профессиональным группам; «контент-аналитик» входит в группу менеджера-аналитика.
- Ограничивает запрос опытом 0 лет и изменениями за последние N дней.
- Проверяет название должности, требование удалённой работы, нормализует ссылку, работодателя, опыт и зарплату.
- Убирает дубликаты ссылок, сохраняет JSON; отсекает вакансии без явных признаков удалённой работы.
- Все найденные карточки всё равно требуют проверки человеком; статус в таблице «На проверку».
- При ошибке API пишет журнал и возвращает ненулевой код выхода, не выдавая частичные данные за успешный сбор.

## Запуск без Google
Из каталога модуля на Python 3.11+:

    python -m unittest discover -p "test_*.py" -v
    python collector.py --group "Копирайтер" --group "Контент-менеджер" --days 14 --limit 15

Результаты: vacancies.json и summary.json. Сборщик не меняет Google Таблицу без явного --write-sheet.

## Подключение к Google Таблице
Назначение: существующий лист «Вакансии по группам», столбцы A:K.
Скрипт проверяет заголовки и существующие URL, чтобы не дублировать и не перезаписывать действия владельца.

Для автономной записи через GitHub Actions потребуется отдельная авторизация:
1. В Google Cloud включить Sheets API, создать сервисный аккаунт.
2. Предоставить его client_email право «Редактор» только на таблицу «Карьерный радар».
3. Поместить JSON ключ в GitHub Actions secret с именем GOOGLE_SERVICE_ACCOUNT_JSON.
4. Добавить второй secret GOOGLE_SPREADSHEET_ID — идентификатор имеющейся таблицы.
5. Не выкладывать ключи, личные адреса и доступ к аккаунтам в исходники.

На Python установить зависимости: pip install -r requirements.txt
Для записи: python collector.py --group "Копирайтер" --write-sheet
При любой ошибке API программа не пишет частичный результат в Google.

## GitHub Actions
Файл: .github/workflows/career-radar-trudvsem.yml

Проверяет тесты на отдельной feature-ветке.
После переноса workflow в ветку main можно вручную запускать dry-run и write-sheet.
Регулярное расписание специально отключено, пока не пройдёт проверка API,
GitHub Actions и записи в Google с безопасными учётными данными.

## Качество и ограничения
Указание на удалённую работу в тексте объявления — предварительный признак.
Сайт может возвращать нерелевантные должности; применяется дополнительный фильтр названий.
Доступность работы для конкретного региона, оформление и дата актуальности требуют проверки.
При перепубликации вакансия может быть изменена. Для проверки всегда сохраняется исходная ссылка.

Документация API: https://trudvsem.ru/opendata/api
